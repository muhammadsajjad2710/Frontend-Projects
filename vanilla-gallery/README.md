# Image Gallery

Click a tile to feature it. Tiles are colored placeholders, no downloads.

Framework: **Vanilla JS**

Open `index.html` in a browser, or from this folder:

```powershell
cd D:\AI-Agents\Frontend-Projects\vanilla-gallery
python -m http.server 5500 --bind 127.0.0.1
```

Then open http://127.0.0.1:5500
